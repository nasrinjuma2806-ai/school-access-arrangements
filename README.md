# school-access-arrangements
 Demonstration project - generates draft emails using fictional data. No real student data is used and no emails are sent automatically.
## Why I built it
I was spending hours manually checking spreadsheets and emailing teachers about arrangements like extra time, exam evidence, and separate rooms. I automated it to generate all draft emails in seconds.
## how it works
- Reads sample CSV with Teachers, Students, Subject, Examdates, Arrangement
- Uses python functions to create personalised reminder emails
- Print draft email ready to send
## Tech used 
- Python
- CSV handling
- Functions
