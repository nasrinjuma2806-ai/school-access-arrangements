# school-access-arrangements
 Automates reminder emails for 150+ students regarding school access arrangements using CSV data and Python. That took really long time to do manually.
## Why I built it
I was spending hours manually checking spreadsheets and emailing teachers about arrangements like extra time, exam evidence, and separate rooms. I automated it to generate all draft emails in seconds.
## how it works
- Reads CSV with Teachers, Students, Subject, Examdates, Arrangement
- Uses python functions to to create personalised reminder emails
- Print draft email ready to send
## Tech used 
- Python
- CSV handling
- Functions
